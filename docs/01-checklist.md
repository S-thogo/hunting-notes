# 必要な物の一覧

千葉県(住所地)と栃木県(県外)でわな猟の登録をして猟をするときに要る物。手続きの細部は [02-chiba.md](02-chiba.md)・[03-tochigi.md](03-tochigi.md) を参照。

## 1. ずっと持っておく物

- [ ] 狩猟免状(わな猟)。千葉県知事が交付。有効期間は合格日から3年を経過した日の属する年の9月14日まで → 更新は [05-license.md](05-license.md)
- [ ] 保険(共済)。狩猟中の事故の賠償が3,000万円以上で、わな猟中の事故も対象になっているもの。毎年、今年度分になっているか確かめる

## 2. 毎年の登録申請に要る物

免許の種類ごと・県ごとに1式ずつ要る。銃猟も登録するなら、銃猟の分は別に用意する。

| 物 | 千葉県(県内在住) | 栃木県(県外在住) |
| --- | --- | --- |
| 狩猟者登録申請書 | 1部(千葉県の様式・両面印刷) | 1部(栃木県の県外用の様式・両面印刷) |
| 写真 | 2枚(1枚は申請書に貼る) | 2枚(申請書に1枚+登録証用に1枚) |
| 損害賠償能力の証明書 | 1部 | 1部 |
| 狩猟免状 | 写しの添付は求められていない。申請書に免状番号と交付日を書く | 写し1部(条件あり・下記) |
| 登録手数料 | 1,800円 | 1,800円 |
| 狩猟税(わな猟) | 8,200円(軽減あり) | 8,200円(軽減あり) |
| 狩猟税の軽減を受けるための証明 | 該当する人だけ | 該当する人だけ |
| 登録証の受け取り | 窓口で受け取る | 郵送。着払いか、レターパック(同封するか600円を払う) |

### 写真の決まり(両県共通)

- 縦3.0cm × 横2.4cm
- 申請前6か月以内に撮影したもの。無帽・正面・上三分身・無背景
- 裏に氏名と撮影年月日を書く
- 免状に眼鏡などの条件がある人は眼鏡をかけて撮る(コンタクトレンズの場合はその旨を書く)
- ちば電子申請では写真をデータ(png / jpeg)で付ける

### 損害賠償能力の証明書(どれか1つ)

- 大日本猟友会の共済の被共済者であることの証明書(今年度のもの)
- 損害保険の保険証書の写し、または付保証明書。狩猟の賠償が付いていることが分かる箇所にマーカーを引く。証書に書いていなければ約款の該当箇所も付ける
- 資産の証明書(預金残高証明書など)

申請先の数だけ要る(例: 千葉県のわな猟と栃木県のわな猟で2部)。

### 栃木県に出す狩猟免状の写し

次のどちらか1部。

- 狩猟者登録のために今年度に再交付を受けた狩猟免状。千葉県で「他県の狩猟者登録用」の再交付を受けられる(1枚1,000円) → [05-license.md](05-license.md)
- 今年度に、大日本猟友会の会員である猟友会(千葉県猟友会など)の会長が「原本に相違ない」と認めた写し。猟友会の会員なら所属の猟友会に頼む

## 3. 猟に出るときの持ち物

- [ ] 狩猟者登録証(猟をする県のもの)。狩猟中は持ち歩き、求められたら見せる
- [ ] 狩猟者記章(登録のときに交付される)
- [ ] 鳥獣保護区等位置図(登録のときに配られる。両県とも Web 版もある)
- [ ] わな(規格に合ったもの。同時に使えるのは30個まで) → [04-trap-rules.md](04-trap-rules.md)
- [ ] わな1個ごとの標識(住所・氏名・登録した県の知事名・登録年度・登録番号など) → [04-trap-rules.md](04-trap-rules.md)
- [ ] 止め刺しと運び出しの道具

## 4. 豚熱(CSF)対策の物

両県とも、イノシシを扱うときは豚熱を広げない対策を求めている。千葉県のリーフレットが挙げている物:

- [ ] 使い捨てゴム手袋
- [ ] 防護服(夏場はポリエプロンなども可)。捕獲や止め刺しのときに着る
- [ ] 使い捨てマスク・保護メガネ(消毒薬から目・鼻・口を守る)
- [ ] 長靴
- [ ] 消毒薬
  - 逆性石けん: 長靴・車両・器具・地面。適切な濃度で使い、泥を落としてから噴霧する
  - 消石灰: 地面。目などの粘膜に触れないようにする。使うときは土地の持ち主の了解を取る
  - 消毒用アルコール: 手指・防護服や作業服・器具・車内。火気厳禁
- [ ] ブルーシート・ビニールシート(捕獲したイノシシを包む・車に積むとき)
- [ ] 着替え(帰ったら着た物を毎回洗濯する)

消毒のタイミングと捕獲したイノシシの扱いは、[02-chiba.md](02-chiba.md) と [03-tochigi.md](03-tochigi.md) の「豚熱」の節を参照。
