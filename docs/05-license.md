# 狩猟免許の更新と免状の手続き(千葉県)

狩猟免許は住所地の都道府県(千葉県)で更新する。令和8年度(2026年度)の県の案内をもとにしている。

## 有効期間

- 狩猟免許試験に合格した日から3年を経過した日の属する年の9月14日まで
- 例: 2026年に合格 → 2029年9月14日まで。2029年の5〜8月ごろに更新の手続きをする
- その年の9月14日に有効期間が終わる人が、その年度の更新の対象になる

## 更新の手続き(令和8年度の例)

- 受付: 適性検査の日程ごとに受付期間がある(令和8年度は5月15日〜8月7日の間に12回分)
- 適性検査(わな猟免許): 視力(両眼0.5以上、矯正可)、聴力(10m離れて90デシベルの警音器の音が聞こえる、補聴器可)、運動能力。眼鏡・補聴器を使う人は持って行く
- 講習: 会場での講習はなく、テキストか動画で自宅で学ぶ(令和8年度)

必要な物:

- [ ] 狩猟免許更新申請書 1部(免許が2種類以上でも1部。両面印刷のA4 1枚)
- [ ] 写真: 更新する免許1種類につき1枚(縦3.0cm × 横2.4cm、6か月以内、無帽・正面・上三分身・無背景、裏に氏名と撮影年月日)
- [ ] 医師の診断書(原本) 1部。申請日から1年以内に診断されたもの。銃砲の所持許可証の写しで代えられる場合がある
- [ ] 狩猟免状(原本)
- [ ] 受講票を送ってもらうための110円切手 1枚
- [ ] 手数料: 1種類につき2,900円。令和8年度は、窓口・郵送は千葉県収入証紙、ちば電子申請ならクレジットカード・コード決済(PayPay・d払い・au PAY)・ペイジー。収入証紙は2026年12月で販売が終わるので、次の更新では払い方を確かめる

ちば電子申請で出す場合は、写真をデータで付け、診断書と免状の原本を簡易書留など(特定記録・レターパックも可)で送る。受講票はメールで届くので、A4で印刷して適性検査の日に持って行く。

提出先は狩猟者登録と同じ(千葉市・市原市は自然保護課、それ以外は管轄の地域振興事務所)。

## 他県の登録用に免状を再交付してもらう

栃木県に出す「今年度に再交付を受けた狩猟免状」は、千葉県で再交付を受ける。

- 対象: 千葉県外の狩猟者登録用に再交付を受けたい人(他県で登録するため免状が複数枚要る人)
- 必要な物: 狩猟免状再交付申請書(上部の「狩猟免状亡失届出書」は二重線で消す)、手数料 1,000円(免状1枚につき。現金の同封は不可)
- 出し方:
  - 窓口(事前に電話。代理人も可)
  - 郵送(返信用に350円切手を貼った封筒を同封し、特定記録郵便で返送される。収入証紙を同封するなら簡易書留。日中に連絡が取れる電話番号を必ず書く)
  - ちば電子申請(手数料はクレジットカード・PayPay・d払い・au PAY・ペイジー)
- 提出先は狩猟者登録と同じ

## 住所・氏名が変わったとき

- 免状: 狩猟免状変更届出書と、持っている免状の原本すべてを、変更後の住所地の県の機関に出す(窓口なら住民票の写しなど変更が分かるものも)。電子申請も可
- 登録証: 狩猟者登録変更届出書と、持っている登録証の原本すべて(窓口なら住民票の写しなど)。栃木県で受けた登録は栃木県に届け出る(方法は栃木県に確かめる)
- 千葉県の届出書は1枚で全種類(網・わな・第一種・第二種)の届出ができる

## 登録証・記章を無くしたとき

- 「狩猟者登録証等亡失届出書」を住所地の県の機関に出す
- 再交付: 登録証は1枚1,100円(写真1枚も要る)、記章は1個1,000円
