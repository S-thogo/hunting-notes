# 栃木県での狩猟者登録(県外在住)

千葉県に住んでいる人が、栃木県でわな猟をするための登録。栃木県の令和8年度(2026年度)の案内のうち「栃木県外にお住まいの方」の項目をもとにしている。

## 受付期間

- 9月1日から狩猟期間の終わりまで(令和8年度は9月1日から)
- 令和8年度は、10月2日までに申請書が届かないと、初猟日までに登録証を出せない場合があるとされていた
- 申請書の受付順に処理し、原則として当日の交付はしない

## 提出先

県外在住者は、一般社団法人 栃木県猟友会に出す。

- 〒320-0051 宇都宮市上戸祭町60-1 栃木防災(株)2階
- 電話 028-611-1526 / FAX 028-611-1675
- 封筒に「狩猟者登録申請書在中」と朱書きする
- 窓口に持って行けるかは案内に書かれていない。持参したいときは電話で確かめる

千葉県猟友会を経由する必要はない。千葉県猟友会が関わるのは、免状の写しの原本証明を頼む場合だけ(下記)。

## 必要な物

[01-checklist.md](01-checklist.md) の「栃木県」の列。

### 狩猟免状の写し(県外在住者だけ)

次のどちらか1部。

- 狩猟者登録のために今年度に再交付を受けた狩猟免状。千葉県で「千葉県外の狩猟者登録用」として再交付を受ける(1枚1,000円) → [05-license.md](05-license.md)
- 今年度に、大日本猟友会の会員である猟友会の会長が「原本に相違ない」と認めた狩猟免状の写し。千葉県猟友会の会員なら、所属の猟友会に頼む

### 申請書(栃木県の県外用様式: 別記様式第16号)

- 県の案内のページから Word か PDF を取って、両面印刷する
- 免許の種類ごとに1部
- 表面に「狩猟税額記入欄」と「手数料を納付したことを証する書類の添付欄」がある。振込の控えの付け方は猟友会に確かめる
- (2) 狩猟をする場所: 通常は「1 栃木県の区域全部」
- (7) 保険(共済)の内容を書く
- 写真は申請書に1枚、登録証用に1枚

## お金

| 項目 | 額 | 払い方 |
| --- | --- | --- |
| 登録手数料 | 1,800円(免許の種類ごと) | 現金書留か、指定の銀行口座への振込 |
| 狩猟税(わな猟) | 8,200円(道府県民税の所得割を納めなくてよい人などは5,500円) | 同上 |
| 返送料 | 着払い(郵便か宅配)。レターパックを希望するなら、宛先を書いたレターパックを同封するか、600円を税と一緒に払う | — |

- 振込先の口座は県の案内に載っている。年度ごとに確かめる
- 一度払った狩猟税・手数料は返ってこない
- 許可捕獲の従事者などの軽減と、対象鳥獣捕獲員の非課税もある。証明書類の種類は県の案内で確かめる

## 登録証を受け取る

- 猟友会から、登録証・狩猟者記章・鳥獣保護区等位置図が郵送(または宅配)で届く
- 位置図は県のページに Web 版(PDF)もある。令和8年度は、地図面が白紙の不良品が一部混ざっていたとして差し替えを受け付けていた

## 猟期と区域

- 狩猟期間: 11月15日〜翌年2月15日
- イノシシ・ニホンジカの延長: 次の20市町では11月1日〜翌年3月15日。ただし11月1日〜14日に使えるのはわなだけ(銃は、わなにかかったシカ・イノシシの止め刺しのときだけ)
  - 宇都宮市、足利市、栃木市、佐野市、鹿沼市、日光市、真岡市、大田原市、矢板市、那須塩原市、さくら市、那須烏山市、益子町、茂木町、市貝町、芳賀町、塩谷町、高根沢町、那須町、那珂川町
  - 延長がないのは小山市、下野市、上三川町、壬生町、野木町
  - この内容は県の「狩猟制度」のページ(2022年12月更新)による。何年度まで続くかは未確認なので、毎年確かめる

## ツキノワグマの錯誤捕獲を防ぐ

栃木県の西部の山間地はツキノワグマの生息地で、イノシシ猟などのわなにクマがかかることがある。

- ツキノワグマを狩猟でわなを使って捕ることは禁止されている
- クマがかからないよう、わなの設置場所や餌に気をつける
- 錯誤捕獲を早く見つけて対処できるよう、わなは定期的に見回る
- 箱わなは、天井の中央に30cm四方の穴を開けておくと、イノシシは中に残り、クマは逃げられる(穴を壁際に寄せるとイノシシが逃げる)
- くくりわなは、輪の直径12cm超・締付け防止金具なしは使用禁止。シカ・イノシシ用はさらに、よりもどしなし・ワイヤーの直径4mm未満も禁止。輪の直径は一部地域で緩和あり(範囲は未確認)
- クマがかかったら、所管の環境森林事務所か森林管理事務所に相談する。放獣の費用は原則としてわなの持ち主が負担する

## 豚熱(CSF)

県内の野生イノシシで感染が確認されていて、2026年11月20日には県内の養豚場でも発生が確認された。

- 入猟の前後に、靴・衣類・道具・手指・車両などを消毒する
- 狩猟のあと当分の間(1週間)は、養豚場などの家畜を飼っている施設に立ち入らない
- 感染確認区域(陽性のイノシシが見つかった地点から半径10km)で捕獲したイノシシと、その肉・内臓・血液は、原則として区域の外へ持ち出さない
- 野生イノシシの不審な死体を見つけたら、最寄りの県環境森林事務所か矢板森林管理事務所に連絡する

## 猟期が終わったら

- 捕獲の結果の報告と登録証の返納(法律上、登録の有効期間の終了後30日以内)。返し先と様式は、登録証と一緒に届く案内で確かめる
