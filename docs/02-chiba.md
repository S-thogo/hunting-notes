# 千葉県での狩猟者登録(県内在住)

千葉県に住んでいる人が、千葉県でわな猟をするための登録。令和8年度(2026年度)の県の案内をもとにしている。

## 受付期間

- 10月1日から狩猟期間の終わりまで(令和8年度は10月1日〜2027年2月15日)
- 月〜金(祝日を除く)。県庁の自然保護課の受付は 9:00〜12:00、13:00〜17:00
- 郵送の場合、10月17日以降に届いたものは、11月15日(猟期の初日)までに登録証を出せないことがある
- 猟期中でも申請できる。銃猟を先に登録していても、わな猟は別の申請として出せばよい

## 提出先

住所地を管轄する県の機関に、本人が直接出す(猟友会を経由する手続きは県の案内には無い)。

- 千葉市・市原市: 環境生活部 自然保護課 狩猟・保護班(千葉市中央区市場町1-1 本庁舎4階、043-223-2972)
- それ以外: 管轄の地域振興事務所(葛南・東葛飾・印旛・香取・海匝・山武・長生・夷隅・安房・君津)。管轄と電話番号は県の案内の表で確認

## 出し方

次のどれか1つ。窓口に行くときは、前もって電話で日時を伝える。

1. ちば電子申請: オンラインで申請し、手数料もオンラインで払う。写真はデータで付ける。そのあと、申請書以外の書類(損害賠償能力の証明書など)を「郵送書類チェックリスト」と一緒に郵送する
2. 郵送: 書類一式を管轄の機関へ送る
3. 窓口: 書類を持って行く。自然保護課なら平日15時までに申請すれば、その日のうちに登録証を受け取れる

## 必要な物

[01-checklist.md](01-checklist.md) の「千葉県」の列。

## 申請書の書き方(第十六号様式)

- 免許の種類ごとに1部。両面印刷(片面コピーは不可)
- (1) 「わな猟免許」にチェックし、知事名(千葉県知事)・免状番号・交付年月日を書く
- (2) 狩猟をする場所: 通常は「1 県の区域全部」
- (3)(4) 許可捕獲・認定事業の従事者や対象鳥獣捕獲員に当たるか(狩猟税の軽減に関わる)
- (6) 銃の所持許可の欄は、わな猟では書かない
- (7) 保険(共済)の法人名・会社名、対象の損害、金額、期間
- (8) 職業、(9) 個人情報の扱いへの同意
- 連絡が取れる電話番号を書く。押印はなくてよい
- 写真を1枚貼り、もう1枚は添える

## お金

| 項目 | 額 | 払い方 |
| --- | --- | --- |
| 登録手数料 | 1,800円(免許の種類ごと) | キャッシュレス(自然保護課の窓口・ちば電子申請)か千葉県収入証紙 |
| 狩猟税(わな猟) | 8,200円 | 現金 |

- 千葉県収入証紙は2026年12月末で販売が終わる。2027年以降はキャッシュレスで払う前提で考える。地域振興事務所の窓口は令和8年度時点でキャッシュレス端末を準備中で、窓口では証紙払いだったので、事前の電話で払い方を確かめる
- 狩猟税の払い方(自然保護課の場合): 窓口で15時までに申請すると、総務部税務課で納付書が出る。電子申請・郵送の場合は、登録証の交付日に窓口で納付書をもらって払い、そのあと登録証を受け取る。地域振興事務所の場合は事務所に確認する

### 狩猟税(わな猟)の軽減

| 区分 | 税額 |
| --- | --- |
| 通常 | 8,200円 |
| 道府県民税の所得割を納めなくてよい人(扶養されている人は原則対象外) | 5,500円 |
| 鳥獣捕獲許可による捕獲(有害鳥獣の捕獲など)をした人・従事した人(期間や区域の条件あり) | 4,100円(上の5,500円に当たる人は2,700円) |
| 対象鳥獣捕獲員、認定鳥獣捕獲等事業者の捕獲従事者 | 非課税 |

軽減を受けるには証明書類が要る(市町村長の証明書、許可証や従事者証の写しなど)。種類は郵送書類チェックリストを参照。半額の軽減と非課税は重ねて受けられない。

## 登録証を受け取ったら

- 申請内容の確認後、県から交付日の連絡がある
- 登録証・記章・鳥獣保護区等位置図を受け取る(位置図は県のページで PDF でも見られる。令和8年度版には正誤表がある)
- 登録証を受け取るまでは、わなを掛けない

## 猟期と区域

- 狩猟期間: 11月15日〜翌年2月15日。令和8年度はイノシシ・ニホンジカの延長はなかった
- イノシシ・ニホンジカ用の足くくりわなは、輪の直径15cm以下まで使える(狩猟だけに認められた千葉県の緩和。許可捕獲は許可の条件に従う)
- ニホンジカの捕獲頭数の制限はない
- わなを使えない区域(鳥獣保護区、特定猟具使用禁止区域(わな)など)は、位置図と県の一覧で確かめる

## 豚熱(CSF)

県内の養豚場で発生しており、令和8年度には県内の野生イノシシでも感染が確認された。イノシシの捕獲作業(捕れなかった場合も含む)では、県の防疫措置マニュアルに沿って感染を広げないようにする。

- 長靴、車両(タイヤ・荷台・足マット)、使った器具(捕獲器具・止め刺し用の器具・計測器具)、手袋、手指を、現地に着いたとき・作業が終わったとき・現地を出る前・帰宅後のうち決められたタイミングで消毒する(どれをいつ消毒するかはリーフレットの表を参照)
- 血液や糞が付いたまま移動しない
- 入猟のとき、感染確認区域とそれ以外の区域を行き来しない(令和8年度の登録案内)
- 感染確認区域(感染した野生イノシシが見つかった場所から半径10km)で捕獲したイノシシの死体・肉・内臓・血液は、原則として区域の外に持ち出さない。焼却のために運び出すのは、血液などが漏れないようにすれば可
- 運ぶとき: イノシシの体の表面を消毒し、ブルーシートで包んで外側も消毒する。車にはビニールシートを敷く。運ぶ途中で血液などが漏れたら消毒する
- 現地で埋めるとき: 十分深い穴に消石灰を入れ、死体を置いて上から消石灰をまき、土で埋めて表面にも消石灰をまく
- 捕獲した場所の周りは、地面が濡れる程度に消毒薬をまく(できれば消石灰も)
- 猟犬は出発前と帰宅後に洗い、リードなどの道具は帰宅後に消毒する
- 帰ったら入浴し、着た物は毎回洗濯する。当面は養豚関連の施設に立ち入らない
- 死んだイノシシを見つけたら、最寄りの家畜保健衛生所か市町村に連絡する

## 猟期が終わったら

- 登録証を、発行した機関へ返す(郵送も可)
- 捕獲の結果を報告する(法律上、登録の有効期間の終了後30日以内)。様式は登録証の交付時の案内で確かめる
