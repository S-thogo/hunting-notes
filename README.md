# hunting-notes

千葉県と栃木県でわな猟をするための手続きと、必要な物をまとめたメモです。狩猟者登録は毎年必要なので、申請の時期にここを見返し、変わったところを直していきます。

- 前提: 千葉県に住んでいて、千葉県の狩猟免許(わな猟)を持っている。栃木県には県外在住者として登録する。
- 内容は 2026年11月時点の各県の案内(令和8年度)に基づく。日付・金額・提出先は年度ごとに変わることがあるので、申請の前に各県の最新の案内で確かめる。

## 提出先のまとめ

| | 千葉県(住所地) | 栃木県(県外在住) |
| --- | --- | --- |
| 提出先 | 県の機関。千葉市・市原市は県庁の自然保護課、それ以外は管轄の地域振興事務所 | 一般社団法人 栃木県猟友会 |
| 出し方 | ちば電子申請・郵送・窓口(窓口は事前に電話) | 郵送 |
| お金の払い方 | 手数料はキャッシュレスか収入証紙、狩猟税は現金 | 手数料・狩猟税とも現金書留か指定口座への振込 |
| 受付開始(令和8年度) | 10月1日 | 9月1日 |
| 登録証の受け取り | 窓口で受け取る(自然保護課の窓口は15時までの申請で即日交付も可) | 郵送で届く |

千葉県の申請は猟友会を経由せず、県に直接出す。千葉県猟友会が関わるのは、栃木県に出す狩猟免状の写しの原本証明を頼む場合だけ([docs/03-tochigi.md](docs/03-tochigi.md))。

## 1年の流れ

日付は令和8年度(2026年度)の例。

| 時期 | やること |
| --- | --- |
| 5〜8月(3年に1回) | 狩猟免許の更新。千葉県で適性検査を受ける → [05](docs/05-license.md) |
| 申請の前(8月ごろ) | 保険(共済)が今年度の猟期をカバーしているか確かめ、証明書を申請先の数だけ用意する。写真を撮る(申請前6か月以内のもの) |
| 申請の前(8月ごろ) | 栃木県に出す狩猟免状の写しを用意する(猟友会長の原本証明か、千葉県での再交付) → [03](docs/03-tochigi.md) |
| 9月1日〜 | 栃木県の受付開始。令和8年度は10月2日までに届かないと初猟日に間に合わない場合があった → [03](docs/03-tochigi.md) |
| 10月1日〜 | 千葉県の受付開始。郵送なら10月16日までに届くように → [02](docs/02-chiba.md) |
| 11月1日 | 栃木県の延長区域でイノシシ・ニホンジカの猟期が始まる(11月14日まではわなだけ) |
| 11月15日 | 両県の猟期開始 |
| 2月15日 | 両県の猟期終了(栃木県の延長区域のイノシシ・ニホンジカは3月15日まで) |
| 登録の有効期間の終了後30日以内 | 捕獲の結果を報告し、登録証を返す(両県とも) |

猟期中でも登録の申請はできる(千葉県は猟期中の平日、栃木県も狩猟期間内は受付)。猟期の途中から登録しても、手数料と狩猟税は同じ額。

## 費用の目安(わな猟、通常の税額)

| 項目 | 千葉県 | 栃木県 |
| --- | --- | --- |
| 登録手数料 | 1,800円 | 1,800円 |
| 狩猟税(わな猟) | 8,200円 | 8,200円 |
| その他 | — | 登録証の返送料(着払いかレターパック)、現金書留・振込の手数料 |
| 計 | 10,000円 | 10,000円+送料など |

ほかに、写真代、保険(共済)の掛金、栃木県用に免状を再交付する場合の手数料(1枚1,000円)がかかる。狩猟税は条件によって軽くなる(各県の手順を参照)。

## まだ確認できていないこと

- 捕獲報告の様式と出し方(両県)。法律上は、登録の有効期間の終了後30日以内に報告する義務がある。登録証を受け取ったときの案内で確かめる
- 栃木県のイノシシ・ニホンジカの猟期延長が何年度まで続くか
- 栃木県で、くくりわなの輪の直径の緩和がある「一部地域」の範囲
- わなの標識について、千葉県・栃木県それぞれに独自の指定があるか
- 狩猟者記章の着用が義務か努力義務か
